# TinyLog — main page

TinyLog is a mobile web app for parents of a newborn. It answers one
question at any moment: is the baby awake or asleep, and since when. And
it lets a parent record what just happened in a single tap, one-handed,
half asleep.

This brief is for the main page only. No history, statistics, settings, or
accounts.

## Recording must be effortless

One tap records what happened. The moment you tap, it is saved. Nothing
is asked first, nothing has to be confirmed, and nothing is required.

Details are welcome but always optional. How much milk, which side, or "it
actually started fifteen minutes ago" each take one more tap. If the
parent adds none of them, the record is still complete.

Time is always "now" when you tap. Adjusting it afterwards moves in
five-minute steps and never into the future.

There is always a way to undo the last thing you did, and any earlier
entry can be opened, corrected, or deleted.

## The baby is always in one state

At any moment the baby is either awake, asleep for the night, or napping.
The app shows which one, and for how long.

The state changes only through what the parent records:

- While awake, the parent can start a sleep, start a nap, or record a
  breast or bottle feed. A feed does not change the state.
- While asleep or napping, the parent can wake the baby up, or record a
  feed.
- A feed during sleep means the baby woke up. The sleep ends at the feed,
  and the baby is awake until the parent starts a new sleep. If the baby
  never really woke, the parent can mark that feed "stayed asleep", and
  the sleep continues as if uninterrupted.
- Starting a sleep while a nap is running (or the other way round) simply
  ends the one and begins the other.

Only the actions that make sense in the current state are offered.
"Wake up" is not an entry of its own; it is the end of a sleep or nap.

## What a feed and a sleep contain

- A feed: the time, breast or bottle, and optionally the side for breast
  and the amount in millilitres for either.
- A sleep or nap: when it started, and when it ended. Until it ends, it is
  shown as still going.

## What the main page shows

- The current state and how long it has lasted.
- Today at a glance: how many feeds and how much milk, how much sleep,
  and how long since the last feed.
- Today's entries, newest first. A night sleep that ended this morning
  belongs to today.

## Things that must not go wrong

- Everything stays on the phone. Closing the app and coming back hours
  later shows the right state and the right elapsed time.
- Tapping the same thing twice by accident does not create a mess.
- A sleep that crosses midnight is one sleep, not two.

## Not part of this page

History and trends, export, multiple children, growth, diapers, medicine,
reminders, sharing between phones.
