# TinyLog — main page

TinyLog is a mobile web app for parents of a newborn. This brief is for
the main page only.

## Goal

A parent, half asleep and holding the baby with one hand, records what
just happened without thinking. Recording must be so simple that it
never feels like data entry: one action records the event, and any
detail beyond that is optional. Nothing is ever asked before the event is
saved.

## The baby is always in one state

The baby is either awake, asleep for the night, or napping. The app
always knows which, shows it, and shows how long it has been so. What the
parent records moves the baby from one state to the next: starting a
sleep or nap, waking up, feeding. Only what makes sense in the current
state is offered. The parent should never have to keep the states
consistent themselves; the app does that.

## What matters

Feeds (breast or bottle) and sleep (night sleep and naps), for today.

## Not part of this page

History and trends, export, multiple children, growth, diapers, medicine,
reminders, sharing between phones.
